# RxJS Learning

This repository contains code snippets and examples that I've created while learning RxJS. RxJS (Reactive Extensions for JavaScript) is a library for composing asynchronous and event-based programs using Observables.

## Purpose

The purpose of this repository is to help me practice and understand various concepts of RxJS, including Observables, Operators, Subscription, and how to manage asynchronous data streams.

## Code Examples

The repository includes different code snippets demonstrating:
- Creating Observables
- Using Operators (`map`, etc.)
- Handling asynchronous events
- Subscribing and unsubscribing to Observables
- Error handling and completion

## Setup

To run the code examples, follow these steps:

1. Clone the repository:

    ```powershell
    git clone https://github.com/your-username/rxjs_learning.git
    ```

2. Install the required dependencies:

    ```powershell
    cd rxjs_learning
    npm install
    ```

3. Run the example scripts:

    ```powershell
    npm start run 
    ```
